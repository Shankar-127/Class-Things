# Class Things

A responsive React + Tailwind CSS single-page study-resource interface.

## Run locally

```bash
npm install
npm run dev
```

Use the header navigation to switch between Home, Recents, Games, and the Creator page. Games includes Number Guess, Rock Paper Scissors, Quick Math, Tic-Tac-Toe, Memory Match, Coin Flip, Dice Roll, Word Scramble, Hangman, and Reaction Test. `npm run build` creates a production bundle in `dist/`.
